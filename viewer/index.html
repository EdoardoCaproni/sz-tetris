SZ-Tetris

Tetris with only S and Z pieces. On small boards the game is solved exactly by dynamic programming; the reinforcement-learning methods of the course learn it by playing, and every learned policy is scored against the exact optimum.

On the 6-wide boards every number is exact: a learned policy is frozen and evaluated by iterative policy evaluation on the table of all boards, so the curves have no simulation noise. Method

The game as a Markov decision problem

state x_t = (b_t, p_t) board, piece input u_t = placement 2W − 3 choices dynamics b_{t+1} = f(b_t, p_t, u_t) drop straight down, clear full rows uncertainty p_{t+1} = S or Z, prob. 1/2 each reward r_t = rows cleared termination piece not inside the board (checked before clearing) objective max E[ Σ_t r_t ], no discount

The piece is drawn after the move, so the value can live on the board alone, before the next piece is known: the afterstate (post-decision state).

W(b) = ½ Σ_p max_u [ r(b,p,u) + W(f(b,p,u)) ] W(game over) = 0 V(b,p) = max_u [ r(b,p,u) + W(f(b,p,u)) ]

Total reward with a termination state: value iteration converges if every policy ends with probability 1. Rather than relying on the theorem that alternating S and Z pieces always lose on width 2n with n odd, the code checks it on each board: the largest set of boards where some placement always avoids game over and stays in the set is empty.

Methods

Features for the linear methods (Bertsekas and Tsitsiklis): the column heights, the differences of neighbouring heights, the maximum height, the number of holes and a constant, heights and holes divided by H. Not implemented, cited only: the cross-entropy method, the usual strong baseline on Tetris (Szita and Lőrincz, 2006), and deep Q-networks.
